# 📊 Marketing Performance Dashboard

## Project Overview

This project demonstrates the end-to-end process of analyzing digital marketing performance using **Google Analytics 4 (GA4)** data, **SQL (BigQuery)**, and **Looker Studio**. The objective is to transform raw analytics data into meaningful business insights through SQL analysis and an interactive executive dashboard.

---

## Business Problem

Marketing teams collect large amounts of website and campaign data every day. However, raw data alone does not provide actionable insights. This project focuses on analyzing user acquisition, engagement, conversions, and revenue to support data-driven marketing decisions.

---

## Project Objectives

- Analyze website traffic using GA4 data
- Measure user acquisition and engagement
- Evaluate marketing channel performance
- Identify top landing pages
- Compare device usage
- Visualize geographic distribution of users
- Analyze the conversion funnel
- Measure revenue generated by different marketing channels

## Data Sources & Methodology

This portfolio contains two separate analytical components.

### 1. Looker Studio Dashboard

The Marketing Performance Dashboard presents website performance metrics, including users, sessions, engagement, purchases, revenue, device performance, marketing channels, and landing pages.

- **Reporting tool:** Google Looker Studio
- **Data source:** The data source configured in the existing Looker Studio report
- **Reporting period:** June 21 – July 18, 2026
- **Last updated:** July 19, 2026

Dashboard metrics reflect the report's configured data source and reporting period. They should not be interpreted as results generated by the SQL scripts in this repository.

### 2. SQL Analytics

The repository contains eight SQL scripts demonstrating marketing analytics queries, including KPI calculations, traffic trends, channel performance, device analysis, landing-page analysis, geographic analysis, funnel analysis, and revenue analysis.

- **Query environment:** Google BigQuery
- **Intended dataset:** Google Analytics 4 public sample export (`bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`)
- **Purpose:** Demonstrate how event-level analytics data can be queried to derive marketing performance metrics and business insights.
- **Execution status:** Verify the table references and run the queries in BigQuery before describing their outputs as validated results.

**Important:** The dashboard and SQL scripts are maintained as separate analytical deliverables. The dashboard's reported metrics and the SQL query results may differ because they may use different data sources, reporting periods, and calculation methods.

## Key Business Insights

1. **Strong traffic acquisition:** The dashboard reports 103K users and 133K sessions, providing a baseline for evaluating website reach and engagement.

2. **Mobile-first audience:** Mobile contributes approximately 60K users, compared with approximately 47K from desktop, highlighting the importance of optimizing the website experience for mobile users.

3. **Conversion funnel drop-off:** The funnel shows `page_view` at 95.59%, while `view_item` is at 25.08% and `predicted_top_spenders` at 8.2%. This indicates substantial variation across tracked events and identifies stages for further funnel investigation.

4. **Revenue and purchase performance:** The dashboard reports $363K in revenue and 2.2K e-commerce purchases. These metrics can be monitored alongside channel-level revenue to evaluate marketing performance.
