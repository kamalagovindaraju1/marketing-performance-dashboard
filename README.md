# 📊 Marketing Performance Dashboard

## Project Overview

This project demonstrates the end-to-end process of analyzing digital marketing performance using **Google Analytics 4 (GA4)** data, **SQL (BigQuery)**, and **Looker Studio**. The objective is to transform raw analytics data into meaningful business insights through SQL analysis and an interactive executive dashboard.

---

## Business Problem

Marketing teams collect large amounts of website and campaign data every day. However, raw data alone does not provide actionable insights. This project focuses on analyzing user acquisition, engagement, conversions, and revenue to support data-driven marketing decisions.

---

## Project Objectives

- Analyze website traffic using GA4 data
- Measure user acquisition and engagement
- Evaluate marketing channel performance
- Identify top landing pages
- Compare device usage
- Visualize geographic distribution of users
- Analyze the conversion funnel
- Measure revenue generated by different marketing channels

## Dataset & Data Source

- **Analytics platform:** Google Analytics 4 (GA4)
- **Query environment:** Google BigQuery
- **Data structure:** Event-level data queried using the `events_*` wildcard table pattern
- **Analysis:** Users, sessions, engagement, purchases, revenue, acquisition channels, device performance, landing pages, and conversion funnels
- **SQL scripts:** 8 analysis queries included in this repository
- **Dataset identifier:** Pending verification against the actual BigQuery source

**Reproducibility note:** The SQL files currently use a placeholder table reference (`project.dataset.events_*`). Replace it with the actual BigQuery table path before presenting the queries as directly executable.
